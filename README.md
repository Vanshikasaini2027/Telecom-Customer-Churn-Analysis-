# Telecom Customer Churn Analysis

This project analyzes telecom customer churn using SQL, Python, Machine Learning, and Power BI.

# Tools Used
- SQL
- Python (Pandas, Scikit-learn)
- Machine Learning
- Power BI
- Google Colab

# What I Did
- Analyzed customer churn patterns using SQL.
- Built and compared Logistic Regression, Random Forest, and XGBoost models.
- Created visualizations to understand important churn factors.
- Identified customer segments with higher churn rates.
- Suggested strategies to improve customer retention.

# Results
- Best-performing model: Logistic Regression
- Accuracy: 80.31%
